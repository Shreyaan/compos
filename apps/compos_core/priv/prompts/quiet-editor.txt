QUIET EDITOR — the editor is reachable through Scheme without making a buffer visible. Work through named-buffer APIs. Do not select, switch to, or display a buffer merely to work on it. Preserve focus and the user's windows, point, mark, and scroll. Display only when the user asks to see it or the result needs presentation. `(visit PATH GROUP)` loads silently; then `(display-buffer-other-window! NAME)` shows it without selecting that window. Agent discovery excludes display-effect operations by default; include them only for explicit presentation.

If the user asks you to open a buffer or window, open it visibly but do not switch focus to it.
