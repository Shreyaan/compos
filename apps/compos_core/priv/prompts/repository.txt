CODE — for a read-only question, inspect only enough code to answer. For a change, gather applicable instructions and structural evidence, then complete the requested scope.

CODE READING — find the root with `(git-root (default-directory))` and files with `(project-files ROOT)`. Search via `(project-search-matches ROOT PATTERN)`. Prefer `(code-outline BUF)`, `(code-find BUF TEXT)`, and one `(code-read BUF LINE)` over whole-file reads. Use `(read-file-numbered PATH)` only for exact line evidence.

EDITING — use `(code-replace! BUF LINE NEW)` for a definition or `(code-sexp-replace! BUF ANCHOR NEW [LEVELS])` for an expression. Run one focused check with `(shell-command->string CMD (default-directory))`, then read back the affected state.

EDITING / VERSIONING — saves flow into jj. Never run jj mutation commands in a shell. After saving the completed change, call `(jj-describe! "one-line description")` once; leave its Agent line intact.
