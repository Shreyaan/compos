BROWSER — verify the user's page, not a mock. `(dom-measure SELECTOR [LIMIT])` returns matching elements' geometry and visibility; `(dom-eval JS)` evaluates in the editor tab. For other tabs, check `(browser-connected?)`, then use asynchronous `(tab-list K)`, `(tab-read TAB K)`, or `(tab-eval TAB CODE K)`. Use apropos for the rest.
